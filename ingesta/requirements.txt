# Dependencias de los scripts de ingesta del catálogo (proceso Python separado,
# fuera de la aplicación Next.js). Requiere Python 3.10 o superior.
#
# Instalación (desde la raíz del repositorio):
#   python -m venv .venv
#   .venv\Scripts\activate            (Windows)   |   source .venv/bin/activate   (Linux/macOS)
#   pip install -r ingesta/requirements.txt
#
# Pruebas (solo usan la biblioteca estándar, no necesitan nada más):
#   python -m unittest discover ingesta
#
# El pipeline audita este archivo con pip-audit (azure-pipelines.yml). Todo va
# con versión exacta para que cada instalación sea idéntica y auditable.
